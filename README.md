## 更新方式

整個網站只有一支 `index.html`，用 VS Code 或記事本就能改。

| 想改什麼 | 找哪裡 |
|---|---|
| 顏色、字體 | 檔案最上面 `:root{ }` |
| 名字、定位句 | `<div class="hero">` |
| 首頁四個數字 | `<div class="metrics">` |
| 作品卡片 | `<div class="cards">` |
| 案例的外部連結 | `<p class="golinks">` 內的 `.golink` |
| 新增一個案例 | 複製整塊 `<article class="case">` |
| 換照片 | 丟新檔到 `assets/img/`，改 `<img src="...">` |

圖片有兩種樣式：
- `class="shot"` — 照片，裁切填滿（人像、團隊照、活動照）
- `class="shot doc"` — 文件，完整顯示不裁切（截圖、證書、圖表）

改完存檔 → GitHub 上傳同名檔案覆蓋 → 約 1 分鐘後網站更新。

## 技術說明

- 單一 HTML 檔，零相依套件，零建置流程
- 字體：Google Fonts 的 Noto Serif TC + Noto Sans TC
- 圖片：JPEG，最寬 1200px、progressive
- 響應式：手機 / 平板 / 桌機三段
- 無障礙：鍵盤可操作的圖片燈箱（Esc 關閉）、可見 focus 框、
  尊重 `prefers-reduced-motion`
